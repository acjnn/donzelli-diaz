This post exists to prove that every instrument in the composing room works. It is never published; it is built only when `INCLUDE_DRAFTS=1`, and the test suite walks it at several viewport widths looking for anything that overflows, clips, or breaks.

## Headings, rules, and running text

Body text is set in EB Garamond at a comfortable measure. It should wrap cleanly, never overflow, and keep its rag even on narrow screens. Here is a [link to somewhere](/about) rendered in rust with a dotted underline.

### A third-level heading

Lists behave like this:

- Java services that had to be right by 09:00
- Celery queues humming on DigitalOcean
- SQL-backed AI workflows, stitched with patience

2. Then the marginalia
3. Then the colophon

## Code

Inline `const x = 42` sits in the running text. Blocks get the ink treatment:

```python title="pipeline.py"
def run_pipeline(jobs: list[Job]) -> None:
    """Process jobs with loud failures."""
    for job in jobs:
        try:
            job.execute()
        except Exception as exc:
            notify(job, exc)
            raise
```

## Math

Inline math like $e^{i\pi} + 1 = 0$ flows with the text, and display math stands alone:

$$
\frac{\partial}{\partial t} \Psi = \frac{i\hbar}{2m} \nabla^2 \Psi
$$
